# Procédure alternative

1. Clonez le projet avec la commande: `git clone https://github.com/MarceauAdrar/github_testing base`
2. Ajoutez les dossiers suivants dans *App/* s'ils ne sont pas présents: *Controller*, *Model*, *Vue*.
3. Glissez ce projet dans le dossier *www* de Wamp ou *htdocs* de XAMPP.
5. Personnalisez les variables d'environnement dans le fichier [text](env.php).
